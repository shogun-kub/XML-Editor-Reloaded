# Инструкции для ИИ-ассистентов (Backend)

Этот файл содержит набор правил, контекста и архитектурных ограничений для ИИ-ассистентов, работающих с бэкенд-частью проекта.

## 🌍 Общие правила
- **Язык общения**: Русский.
- **Кодировка файлов**: Всегда используйте UTF-8 без BOM.
- **Стиль работы**: Предпочтительны минимальные, точечные правки. Избегайте массового переписывания или рефакторинга файлов, если об этом не просили напрямую.
- **Автономность**: При возникновении ошибок компиляции или сборки ИИ должен пытаться самостоятельно их исправить до того, как запрашивать помощь у пользователя. Доводите задачу до рабочей сборки.

**Стек**: .NET 10, C#, SQLite. Десктопное приложение с GUI на WPF.

- **Кодировка файлов**: Строго UTF-8 без BOM для всех файлов исходного кода C#.
- **XML-комментарии (Документация)**:
  - Должны быть подробными и строго на английском языке.
  - Обязательно описывайте параметры и структуру возвращаемых данных. Стандартный ответ API включает поля: `error_code`, `error_text`, `data`.
  - Удаляйте системные или сгенерированные ИИ префиксы из имен (например, не начинайте описание со слова "Метод").
  - Не допускайте дублирования блоков `<summary>`.
