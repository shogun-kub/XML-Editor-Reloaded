# XML Editor Reloaded

[English](README.md) | **Русский**

Настольный редактор XML-таблиц `TableData` мода **Jagged Alliance 2 1.13** с просмотром
STI-изображений предметов. Работает с наборами данных v4 и v5, сохраняет неизвестные элементы и
исходное лексическое представление значений, поддерживает русские и английские оверлеи переводов.

> Это неофициальный инструмент. Он не устанавливает и не изменяет сам мод, а редактирует уже
> установленную игру.

## Возможности

- Просмотр и редактирование всех таблиц `TableData` в schema-driven grid.
- Дерево и плоский список таблиц, фильтр, поиск, вкладки и несколько датасетов одновременно.
- Item master-detail, merc gear, shopkeeper, вспомогательные таблицы и вложенные редакторы
  `Map.Cities` и `Map.FacilityTypes`.
- Lookup- и flag-редакторы, переходы по связям, pickers, массовые правки, фильтры и undo/redo.
- Локализационные оверлеи: перевод записывается только в оверлей, базовая таблица не меняется.
- Проверка датасета одним отчётом, глобальный поиск по базовым таблицам и оверлеям, экспорт в
  Markdown/CSV.
- Сравнение v4 ↔ v5 по структуре и значениям, копирование строк между датасетами с remap.
- Просмотр STI-изображений Big/Medium/Small с выбором кадра и live-миниатюрами.
- Режим Grid/XML: read-only снимок базовой таблицы, поиск по записи и переход из замечания
  валидации к нужной строке.
- Тёмная, светлая и системная темы; русский и английский интерфейс.

## Требования

- Windows 10 или 11, x64.
- Установленная Jagged Alliance 2 1.13 с каталогом `Data-1.13\TableData`.
- Для framework-dependent варианта — [.NET 10 Desktop Runtime x64](https://dotnet.microsoft.com/download/dotnet/10.0).
  Self-contained варианту отдельный runtime не нужен.

## Скачать и запустить

Скачайте последний релиз на
[странице Releases](https://github.com/shogun-kub/XML-Editor-Reloaded/releases/latest). Рядом с
каждым архивом лежит файл `.sha256`.

| Архив | Что внутри |
|---|---|
| `XmlEditorReloaded-<версия>-win-x64.zip` | Self-contained: .NET runtime уже внутри |
| `XmlEditorReloaded-<версия>-win-x64-framework-dependent.zip` | Меньше по размеру; нужен .NET 10 Desktop Runtime x64 |

1. Распакуйте архив в любую папку.
2. Запустите `XmlEditorReloaded.App.exe`.
3. Нажмите **Обзор** и выберите каталог игры, каталог `Data-1.13` или сразу `Data-1.13\TableData`.
4. Дважды щёлкните таблицу в дереве или списке, чтобы открыть её.

Windows может показать предупреждение SmartScreen: сборка не подписана коммерческим
сертификатом. При необходимости сверьте архив с его `.sha256`.

Для полностью переносимого режима запускайте `start-portable.cmd`. Настройки, layout, метабаза и
лог будут храниться в папке `data` рядом с программой, а не в `%AppData%\XmlEditorReloaded`.

## Типичное использование

### Первый запуск и навигация

Каталог данных выбирается один раз; редактор сам находит `TableData`. Слева есть два режима:
**Дерево** с группировкой по папкам и **Список** с плоским перечнем таблиц. Каждая открытая
таблица получает свою вкладку; вкладки разных датасетов могут быть открыты одновременно.

### Редактирование таблицы

Выберите ячейку и введите новое значение. Для lookup-полей предлагается список отображаемых
имён, а в файле сохраняется исходный идентификатор. **Enter** применяет значение, **Esc**
отменяет текущий ввод. **Ctrl+Z / Ctrl+Y** отменяют и повторяют правки до сохранения.

Сохраните активную таблицу через **Ctrl+S**, все открытые — через **Ctrl+Shift+S**. Отсутствующие
элементы остаются отсутствующими; неизвестные элементы и атрибуты сохраняются при записи.

### Переводы

Выберите язык в редакторе. Правка перевода записывается только в соответствующий оверлей,
например `Russian.Items.xml`; базовая таблица не меняется. Непереведённые поля показываются из
базы с пометкой. Отчёт по переводам помогает найти недостающие, «сиротские» и пустые переводы.

### Проверка, поиск и сравнение

- **F8** проверяет текущую таблицу; **Ctrl+Shift+P** — весь датасет.
- **Ctrl+Shift+F** ищет значения по базовым таблицам и оверлеям.
- Команда **Сравнить** сопоставляет записи v4 и v5 по объявленному ключу, а при его отсутствии —
  по порядку, и показывает структурные и лексические различия.
- Отчёты проверки и сравнения экспортируются в Markdown или CSV.

### Изображения и специальные редакторы

Изображения предметов открываются в размерах Big/Medium/Small с выбором кадра. Item editor
показывает предмет и его подтаблицы, merc gear — пять комплектов снаряжения, а `Map.Cities` и
`Map.FacilityTypes` имеют отдельные вложенные редакторы.

## Безопасность данных

- Записываются только те файлы игры, которые вы явно открыли и сохранили.
- Загрузка и сохранение без изменений не перезаписывают файл.
- Неизвестные элементы и атрибуты сохраняются; порядок элементов и лексика значений не
  нормализуются без необходимости.
- Сохранение атомарное, внешние изменения файла проверяются перед перезаписью.
- Повреждённый XML показывается как ошибка и не исправляется и не перезаписывается автоматически.
- Валидация предупреждает, но ничего не удаляет и не нормализует.
- Автоматического backup XML нет: перед первым редактированием сделайте копию `TableData`.

Настройки, layout, `metadata.sqlite` и `XmlEditorReloaded.log` находятся в
`%AppData%\XmlEditorReloaded` или в каталоге из `XER_APP_DATA` (portable launcher использует
папку `data` рядом с приложением).

## Сообщить об ошибке

Используйте [GitHub Issues](https://github.com/shogun-kub/XML-Editor-Reloaded/issues). Перед
созданием нового issue проверьте последний релиз и поищите похожие проблемы — возможно, ошибка
уже известна.

В отчёт желательно включить:

- версию приложения из окна **О программе**;
- версию Windows и вариант релиза (self-contained или framework-dependent);
- версию датасета (v4 или v5) и название таблицы;
- точные шаги воспроизведения, ожидаемое и фактическое поведение;
- полный текст ошибки и, если относится к делу, `XmlEditorReloaded.log`;
- скриншот, если он помогает объяснить проблему.

Не прикладывайте оригинальные файлы `TableData` и другие защищённые авторским правом материалы
игры. Если нужен конкретный XML-фрагмент, добавьте только минимальный обезличенный отрывок.

Если есть подозрение на потерю данных или повреждение файла, прекратите редактирование,
сохраните копию затронутых файлов и явно укажите это в issue. Пожелания по новым возможностям
тоже можно оставлять в issue tracker.

## Сборка из исходников

Требуется .NET 10 SDK.

```powershell
dotnet restore xml-editor-reloaded/XmlEditorReloaded.slnx
dotnet build xml-editor-reloaded/XmlEditorReloaded.slnx -m:1 --no-restore -warnaserror
pwsh -NoProfile -ExecutionPolicy Bypass -File util-scripts/test.ps1
```

Приложение собирается в
`out/bin/XmlEditorReloaded.App/<Configuration>/XmlEditorReloaded.App.exe`. Все `bin`/`obj`
складываются в `out/`.
