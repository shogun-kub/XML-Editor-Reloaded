# M23b5 — автоматизация UI-smoke изображений: журнал

**Дата:** 2026-11-03. **Статус:** выполнен. Автоматизированы S71, S72, S73 и S75; S74 остаётся
ручным, потому что проверяет визуальное обновление миниатюр без перезагрузки. Закрытые пробелы
M23b5 (`L-ITEM-014`, `L-IMG-005`, `L-IMG-020`) не переоткрывались; изменено только поведение
нецелого индекса и добавлены UI-проверки.

## 1. Исходное состояние

M23b8 закрыт (`72d7839`), 600 тестов, 81 автоматизированный сценарий. Вручную оставались S71–S75:
S71/S72/S75 проверяют выбор кадра, перестройку списка и сохранение, S73 — сообщения поля индекса,
S74 — визуальное обновление миниатюр.

## 2. Реализация

- `DetailImagePanelViewModel.InfoAutomationId` + привязка в `ItemWorkspaceView.xaml`:
  `ItemImageBigInfo`/`ItemImageMediumInfo`/`ItemImageSmallInfo` показывают размеры декодированного
  превью или текст ошибки. Это позволило проверять реальный декод, а не только выбранный индекс.
- `ItemWorkspaceViewModel.SetCellValue`: нецелое значение `ubGraphicNum` теперь отклоняется
  `ItemImageIndexInvalid` до записи. Раньше `1.5` могло попасть в XML, потому что специальная
  проверка срабатывала только при успешном `int.TryParse`.
- `ImageUi`: открытие вкладки с повторными попытками (Undo асинхронно возвращает «Поля»), выбор
  кадра с прокруткой виртуализированного `ItemImageList`, чтение выбранного кадра, типа и InfoText.
- Сценарии `ImageFrameScenario` (S71), `ImageTypeScenario` (S72),
  `ImageIndexValidationScenario` (S73), `ImageFramePersistenceScenario` (S75); регистрация в
  `Catalog.cs`.
- Unit-тест `SetItemValue_GraphicIndexNotInteger_IsRejected`.

## 4. Грабли UIA

- `ItemImageList` виртуализирован: `SelectionPattern` не возвращает выбранный кадр, пока строка не
  реализована. Выбор идёт через `ScrollPattern` + `SelectionItemPattern`.
- Undo/Redo асинхронно переключает вкладку на «Поля»; перед Undo нужно оставаться на «Изображениях»,
  а `ImageUi.Open` повторяет выбор вкладки.
- `ValuePattern.SetValue` + синтетический Tab не вызывают `LostFocus` у `ubGraphicNum`; для коммита
  нужен явный перевод фокуса на `ItemGoToIdBox`.
- InfoText панелей скрыт вместе с вкладкой: читать превью до перехода на «Поля».
