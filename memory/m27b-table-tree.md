# M27b — дерево таблиц

**Дата:** 2026-11-04. **Статус:** завершено, S100 PASS на v4.

- Левая панель получила вкладки **«Дерево»** (по умолчанию) и **«Список»**. Старый `TablesGrid`
  сохранён во вкладке «Список»; сценарии, которым нужна плоская таблица, вызывают
  `ScenarioUi.EnsureTableListMode` перед поиском строки.
- `TableTreeViewModel` строит иерархию из `TableDescriptor.RelativePath` (папки — по сегментам,
  лист — имя файла без `.xml`). Порядок: папки, затем файлы, без учёта регистра.
- Фильтр ищет по имени листа, имени файла (с `.xml`), относительному пути и `TableName`; пустые
  папки скрываются, совпавшая папка показывает всех детей. Пустой результат показывает
  локализованную подсказку.
- «Найти в дереве» (`Ctrl+Shift+T`) очищает фильтр, раскрывает только предков выбранной таблицы,
  выбирает лист и переводит фокус в дерево. `Ctrl+F` из дерева/поля фильтра фокусирует фильтр,
  `Esc` очищает его. `Enter` на листе открывает таблицу; Fold/Unfold all работают по всем папкам.
- Выбор листа синхронизирован с общей `SelectedTable`; дерево и список используют один
  `OpenTableCommand`. Шаблон `TreeViewItem` темизирован отдельно, потому что явный
  `ItemContainerStyle` иначе отменяет implicit-стиль и возвращает светлое системное выделение.
- Проверки: 5 unit-тестов `TableTreeViewModelTests`, UI-smoke **S100** (фильтр `Weapons`, открытие
  `Items.Weapons`, Find in tree, Fold/Unfold); S98 перепроверен — PASS (первый прогон дал известный
  флейк `Ctrl+F`, повторный зелёный). Всего 722 unit-теста.
- Ограничения: дерево не показывает оверлеи и не является отдельным file browser; вложенность
  задаётся только путями `TableData`.
