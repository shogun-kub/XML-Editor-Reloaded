- **M22a grid filters, multi-select, layout persistence (2026-10-24, commit `f760102`):** Core gains `Filtering/RowFilterGroup` (flat criteria, `Equals/NotEquals/Contains/GreaterThan/GreaterOrEqual/LessThan/LessOrEqual`, AND/OR) and `Layout/` contracts (`TableLayout`, `ColumnLayout`, `ITableLayoutStore` returning `TableLayout.Empty` when absent — `OperationResult<T>` rejects null data). `Xml.Filtering.TableRowFilterMatcher` compares effective merged values: unknown field never matches; absent field matches only `<>`; numeric types (Integer/Decimal/Lookup/Flags) compare invariantly when both sides parse; text is trimmed/OrdinalIgnoreCase; relational operators are numeric-only; empty group matches all. `Data.Settings.JsonLayoutStore` writes `%AppData%/XmlEditorReloaded/layouts.json` (`schemaVersion: 1`, list of entries keyed by normalized TableData path + table, atomic UTF-8 no BOM); corrupt JSON → `io.error`, save backs it up to `.bad`; newer schema is never overwritten; `ResetAllAsync` deletes the file.
