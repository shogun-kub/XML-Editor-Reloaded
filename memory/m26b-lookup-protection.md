# M26b — защита используемых значений справочника

Дата: 2026-11-04. Коммит: `M26b: lookup usage protection and flag validation`.

## Что сделано

- **`LookupUsageService`** (`Xml/Lookups`): сканирует таблицы, у которых колонка или подсказка ссылается
  на справочник, и возвращает точное число использований плюс ограниченный список (`MaxUsages = 1000`,
  `MaxUsagesPerTable = 200`). Таблица-справочник и таблицы без метаданных пропускаются; повреждённая
  таблица учитывается в `FailedTableCount` и не обрывает скан.
- **Семантика совпадения:** обычный lookup — точное значение; битовая маска — ID 0 совпадает с маской 0,
  одиночный бит — по `(value & id) != 0`, именованная комбинация — только по точной маске (комбинация
  называет ровно этот набор бит). Поэтому значение 3 не считается использованием комбинации 3.
- **Защита в редакторе:** удаление строки и «Изменить ID…» сначала проверяют использования; при
  использовании показывается сообщение с числом и первой записью, изменение не выполняется. Новые
  (неиспользуемые) значения проходят обычный путь, включая подтверждение удаления.
- **Окно «Где используется»** (`LookupUsageWindow`): точное число, список «таблица/запись/поле/значение»,
  пустое состояние; «Открыть» поднимает `TableNavigationRequest` и MainViewModel открывает запись.
- **Валидация flag-lookup:** `LookupFlagMissing` (`validation.lookup_flag_missing`) — предупреждение, если
  маска содержит биты, которым нет имени в справочнике; известные биты = OR всех ID, сообщение перечисляет
  до 8 неизвестных бит. Данные не меняются.
- **UI:** кнопка «Где используется» в тулбаре lookup-таблицы (рядом с «Изменить ID…»), клавиатурные
  сокращения прежние; строки в RESX (en/ru).

## Границы

- Скан читает **сохранённые базовые файлы**; несохранённые правки в других вкладках не видны.
- Оверлеи не сканируются (значения справочников в них не хранятся).
- Комбинация бит защищается только при точном совпадении маски; это осознанное решение, а не пропуск.
- На v5 `Lookup/AttachmentPoint.xml` повреждён, поэтому smoke защиты — на v4.
