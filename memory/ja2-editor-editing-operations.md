- **M16 bulk edits + undo (commit `192e538`, 2026-10-24):** backend `BulkEditRequest`/`BulkEditPreview`/`BulkEditPreviewRow`, `TableWorkspace.PreviewBulk`/`ApplyBulk` (set/add/multiply on one scalar column; existing fields only by default, `IncludeMissingFields` creates them, arithmetic treats absent as 0; keys/list/dict/nested and unknown fields rejected; invariant numbers). `TableEditHistory` snapshots affected record elements before/after (max 50 transactions and 10,000 states) and covers cell edits, set-nested/root, add/duplicate/delete, bulk, and overlay translations; one bulk = one undo step, undo recomputes `IsDirty`, new edits clear redo. `TableDocument.RecomputeDirty` + `SynchronizeRecords` support undo; overlay bulk defers `OverlayWriter.SynchronizeRecords` until the batch ends and indexes top-level overlay elements. UI: `BulkEditWindow` + `BulkEditViewModel` with live preview (only changed/error rows), include-missing checkbox, `IDialogService.EditBulk`; Undo/Redo buttons and Ctrl+Z/Ctrl+Y/Ctrl+Shift+Z in `TableView`; arithmetic resets to Set for non-numeric columns. Perf on real `Items.xml` (~1776 rows): base preview 28–40 ms / apply 91–107 ms / undo 34 ms; v4 overlay translations preview 39–68 ms / apply 751–790 ms / undo 23–27 ms (2 s gate). Planned M16→M17; the `TableView` FullRow selection change is committed separately as `1c284da`.
- **M17 cross-version compare (commit `41e47de`, 2026-10-24):** backend `Xml.Comparison` — `TableDataComparer`/`ITableComparisonService`, `TableSnapshotAnalyzer`, `TableComparisonReportFormatter`, report models. Catalogs both dirs, loads every file through `TableFileLoader` (metadata when available); malformed/unreadable sides do not abort and suppress field diffs for that table. Nested-key tables use descendant records (`CITYLIST/CITY`), others use direct root children. Reports table presence, record counts, field sets in first-appearance order, inferred types (same rules as schema discovery; key is never Boolean), cardinality changes, sparse profile (distinct shapes, min/max/avg fields per record, empty records), overlay languages, and lookup-reference availability from `Columns`+`ColumnHints` (`Available`/`Missing`/`Unreadable`). Export: Markdown (summary/lookup/list/details for changed tables) and long-format CSV (RFC 4180, `Table`/`Field`/`Lookup`/`Warning` rows), UTF-8 no BOM. UI: toolbar “Compare versions…”, `CompareWindow`/`CompareViewModel` with two paths, cancel, summary, table grid, Fields/Lookup tabs, sparse profile + diagnostics, save-file dialog; RESX en/ru. Read-only by construction; env-gated v4↔v5 test hashes both trees before/after. Real v4/v5: 238/239 tables, 238 common, 1 right-only (`Email.EmailSenderNameList`), 25 v4 overlay tables, `Lookup.AttachmentPoint` malformed on v5, Items 1776/1775, Weapons 389/388, Attachments 6079/6023, common tag sets identical; ~1 s.
- **M17 limits if it is extended:** values are not compared, singleton fields of nested tables (e.g. `COUNTRY`) are outside the record profile, overlay contents are not diffed. These were carried into comparison-v2 backlog (M25).
