# M27c — глобальный read-only XML

**Дата:** 2026-11-04. **Статус:** завершён, S101–S104 PASS на v4; S101 и S68 перепроверены после поиска и перехода из валидации.

- Переключатель **Grid/XML** находится справа от вкладок редакторов и действует на все таблицы,
  включая `Items`, `MercGear` и `Map` (специализированные workspace-редакторы). Состояние хранится
  в `MainViewModel.IsXmlMode` и переключается `RadioButton`-сегментами; это не отдельная вкладка
  внутри таблицы.
- `IEditorTab.CreateXmlSnapshot()` реализован всеми четырьмя типами вкладок и возвращает
  `XmlSnapshot` с текстом **базовой** таблицы и позициями открывающих тегов записей. В снимок не
  входят оверлеи и дочерние таблицы workspace.
- XML строится из **текущего in-memory документа** `TableDocument.CreateXmlSnapshot()`, поэтому
  отражает несохранённые правки. Это снимок для чтения, а не байтовое представление файла:
  форматирование сериализатора может отличаться, сохранение по-прежнему идёт через lossless patcher.
- В XML-режиме общий `XmlTextView` заменяет всё содержимое выбранной вкладки: скрыты тулбар,
  поиск, фильтр, выбор колонок, сетка, валидация и специализированные панели. Остаются только
  действия, видимые в текстовом редакторе: поиск записи, копирование и обновление снимка.
- Поиск принимает ID или ключ записи, находит канонический ключ или его отображаемую форму
  (составной ключ с ` | `), выделяет открывающий тег и прокручивает к нему; статус сообщает
  «Найдено»/«Не найдено». Текст не редактируется.
- Список замечаний валидации в Grid-режиме при выборе замечания переходит к его записи. Для
  item-workspace замечания дочерних таблиц не адресуются из базового списка и сообщают свою таблицу.
- Проверки: Xml-тест снимка и `XmlSnapshot.FindRecord`, App-тесты поиска и перехода из валидации;
  UI-smoke **S101** проверяет поиск и выделение `<WEAPON>`, **S68** — переход из замечания Kelly к
  записи 237; **S102** item-workspace, **S103** mercenary-gear, **S104** nested map. Всего 726
  unit-тестов, 98 автоматизированных UI-сценариев.
