# M27c, этап 1 — read-only XML

**Дата:** 2026-11-04. **Статус:** этап 1 завершён, S101 PASS на v4.

- В редакторе таблицы появились вкладки **«Данные»** (прежний грид) и **«XML»**; по умолчанию
  открыты данные, старые UI-сценарии не меняются.
- XML строится из **текущего in-memory документа** `TableDocument.CreateXmlSnapshot()`, поэтому
  отражает несохранённые правки. Это снимок для чтения, а не байтовое представление файла:
  форматирование сериализатора может отличаться, сохранение по-прежнему идёт через lossless patcher.
- Снимок создаётся в фоне при переходе на вкладку XML; кнопка «Обновить XML» повторяет сборку.
  Подпись «Только чтение · базовая таблица» и статус «Сохранено/Есть несохранённые изменения»
  явно объясняют источник. Оверлеи в этот снимок пока не включены.
- Поле `XmlTextBox` — `TextBox` с `IsReadOnly=True`, моноширинным шрифтом, переносами и скроллами;
  кнопка копирует весь снимок в буфер обмена.
- Проверки: `TableDocument.CreateXmlSnapshot()` покрыт Xml-тестом на несохранённую правку; UI-smoke
  **S101** проверяет вкладку, объявление XML, записи, `IsReadOnly`, копирование и возврат к `RowsGrid`.
  Всего 725 unit-тестов, 95 автоматизированных UI-сценариев.
- Дальше по M27c: поиск по ID/ключу и переход из замечания валидации к строке/фрагменту XML.
