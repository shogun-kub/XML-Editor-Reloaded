- **M9 shell + M10 hardening (commit `d8b93c0`):** WPF shell has directory picker, table list, mapped/unmapped/languages, record count and diagnostics; RESX en/ru; `UiLanguageCode` applied once at startup. M10 added env-gated performance gates (numbers in [[ja2-editor-architecture]]), `ThrowIfCancellationRequested` contracts in loader/saver/catalog/provider/imaging (saver checks before serialize, before write and after temp write, so cancellation leaves no file and no temp), strict invariant decimal input in `TableRecord` (no comma/group separators; `xml.invalid_number`), and `MainViewModel` operation generations + error surfacing. 135 tests green, build 0 warnings with `-warnaserror`.
- **M11 workspace foundation (commit `32954c3`):** `Xml.Schema.TableSchemaBuilder` discovers the union of sparse record fields in first-appearance order with presence/max-occurrence counts, inferred types (Boolean only for non-key 0/1 fields, then Integer/Decimal/String), key/list/dict/translatable flags, `Columns` overrides, and declared-but-absent fields; dict masks match by prefix + numeric suffix (`ItemCapacityPerSize%Index%` → `ItemCapacityPerSize0`). `Xml.Workspace.TableWorkspace` loads base + optional overlay by `LanguageDescriptor`, exposes `Schema`, `GetRows()` (`WorkspaceRow.GetValue/GetValues/IsTranslated`; rows fall back to merged-only for nested tables) and `GetRootCells()`, routes edits through `TableEditSession` (now with `addIfMissing`), deletes the overlay translation with a base record, saves base+overlay, validates, and runs `TranslationAnalyzer`. `App.Services.DataSetSessionFactory/DataSetSession` binds `XmlFileLookupRepository` + `TranslationCatalog` to the selected `TableData` and opens tables with metadata resolution/fallback. `TableDocument.SynchronizeRecords()` refreshes the record list after `OverlayWriter` creates or deletes overlay records.
- **M12 grid editor (commit `d32251f`):** `MainViewModel` owns `Editors`/`SelectedEditor` tabs and opens tables via `IDataSetSession`; double-click/Enter/Open create a tab, dirty tabs ask before closing, Save all iterates dirty editors. `TableEditorViewModel` builds schema columns (default = key + 7 scalar fields, key/list/dict read-only), exposes a searchable column chooser, search/sort (typed comparer, missing values last), row commands, validation panel, reload, and dirty marker. `TableRowViewModel` binds through a `[field]` indexer with lazy `WorkspaceRow` reads; empty cells call `addIfMissing`; inferred numeric types are validated before the workspace write (comma/group separators rejected). `TableView` regenerates `DataGridTextColumn`s from `VisibleColumns` and handles header sorting. Overlay-created records refresh one row via `TableWorkspace.GetRow(key)`; nested tables (Cities) display merged rows read-only.
- **Status after M12 (commit `d32251f`):** M0–M12 done; 185 tests green (22 Core, 85 Xml, 25 Data, 19 Imaging, 34 App); real `Items.xml` opens in the grid with 1775 rows and 224 columns; v4/v5 corpora, perf gates and `-warnaserror` green. M13 subsequently added the detail panel and column hints. Known limits carried forward: no undo/redo; list/dict/key cells read-only; nested base tables read-only; column layout not persisted; Boolean cells are text 0/1; `Columns` overrides still unseeded.
- **M13 committed (`ada9c8e`, 2026-10-24):** per-row **detail panel inside the table tab** (works for any table, keeps grid context): `DetailFieldViewModel` calls back into `TableEditorViewModel.SetDetailValue` → `SetCellValue`, so detail edits and sparse add-if-missing reuse the grid path; nested fields are read-only because `workspace.SetValue` only finds direct children. Fields are grouped/filterable with localized fallback groups; three STI panels (Big/Medium/Small) load in parallel with per-panel error codes and are hidden when the table has no `ubGraphicNum`; the 32-bit **unsigned** bit editor (`BitEditorWindow` behind `IDialogService.EditBits`) appears only for `DataType.Flags`/`EditorKind.FlagEditor`. Curated **`ColumnHints`** (migration `0003`, seed `0004`: 224 `Items.Items` fields, 7 flag masks) is **non-declaring** — unlike `Columns`, a hint never makes an absent field appear, preserving sparse semantics. `TableSchemaBuilder` detects nested elements (`ColumnDataType.Nested`, editor `SubTableGrid`, read-only) and assigns `GroupKey`/`GroupOrder` (explicit hint, then identity/nested/lists/flags/text/values fallback). Status: 192 tests green, v4/v5 corpora green, build 0 warnings with `-warnaserror`. Known limits: Boolean flags still edited as text 0/1; nested/list/dict remain read-only; `Columns` still unseeded.
- **M23b7 shell polish (2026-10-26):** Help > About (`AboutWindow`, `AboutViewModel`, `IDialogService.ShowAbout`) shows product/version/description/copyright from assembly metadata and closes by OK/Enter/Esc. Main-window geometry is stored in `AppSettings.WindowPlacement` (`windowPlacement` in `settings.json`), restored before `Show()` via `WindowPlacement.FitToScreen` (raises to `MinWidth/MinHeight`, clamps into the virtual screen, keeps secondary-monitor negativity) and captured on close; minimized closes keep the previous placement, settings are not written before a successful load, and write errors never block closing.
