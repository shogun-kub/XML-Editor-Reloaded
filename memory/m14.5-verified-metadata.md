M14.5 completed on 2026-10-24 in commit `2b8cead` (`M14.5: verified column metadata, hint validation, and 64-bit lookups`). The project is now ready for M15 lookup/flag editors.

- **Seed result:** `0005_VerifiedColumnMetadata.sql` adds 493 hint upserts and 46 declaring columns. Totals: 502 `ColumnHints` across 25 tables and 46 `Columns` across the 23 lookup tables. `Items.Items` still has exactly 224 hints and no `Columns`, preserving sparse semantics.
- **Items types:** 105 Boolean, 87 Integer, 12 Decimal, 8 Flags, 3 Lookup, 6 String (left to discovery), 3 nested. FlagEditor fields: `usItemClass`, `AttachmentClass`, `nasAttachmentClass`, `nasLayoutClass`, `AvailableAttachmentPoint`, `AttachmentPoint`, `DrugType`, `usActionItemFlag`. Lookups: `ubCursor` → `Lookup.Cursor`, `Inseparable` → `Lookup.Separability`, `AttachmentSystem` → `Lookup.AttachmentSystem`.
- **Verification:** 710 raw `MakeColumn` calls in `DatabaseCode.vb` expand to 1,883 definitions; 945 target the 47 seeded tables. 564 fields verified against v4 and v5, 381 stale fields excluded, 0 type mismatches, 0 lookup mismatches for real `Lookup/*.xml` files. 99 legacy lookups into main tables (`ITEM`, `AMMO`, `ITEMTOEXPLOSIVE`, etc.) were deliberately not imported; they need a richer relation model. See `M14.5-METADATA-REPORT.md`.
- **64-bit lookups:** `LookupEntry.Id` is now `long`; `XmlFileLookupRepository` parses 64-bit IDs. `Lookup/ItemFlag.xml` max ID is `8589934592` and now loads. Its `Columns.id` is declared `Raw`; other lookup ids are `Integer`.
- **Validation:** `TableValidator` resolves fields through `Columns` then `ColumnHints` for present fields; unknown-field is emitted only for declaring tables. `TableRecord.ValidateValue` and the App validation path also use hints. Flags validate as `uint` (full 32-bit range), lookups as `long`, integers as `int`, decimals strictly invariant.
- **Tests/verification:** 213 tests (22 Core, 96 Xml, 27 Data, 19 Imaging, 49 App); `RealDataValidationTests` runs on v4/v5 and asserts no false `validation.invalid_type` or `validation.lookup_missing`; `ItemsSchema_UsesVerifiedHints` asserts 224 columns and hint types; both corpora and `-warnaserror` green.

- **M15 delivered** on top of this seed (committed `3f86895`, 220 tests): lookup combos with unknown-ID markers and malformed-lookup text fallback, Boolean checkboxes, named bits from lookup masks. 502 hints / 46 columns unchanged.
- **M15 scope plan (presented 2026-10-24, superseded — M15 shipped, see [[ja2-editor-metadata]]):** (1) lookup combos in grid and detail panel — show name, write ID, respect language, unknown ID shown as raw value with a marker; (2) checkbox for Boolean, named bits in the flag editor, `uint`/`ulong` without overflow; (3) bulk set/add/multiply on a column — only existing fields by default, adding absent fields behind an explicit mode, preview/confirm, invariant culture; (4) read-only v4/v5 cross-version report (fields, types, lookups, record counts, sparse sets). **Open decision for the user:** `PROJECT-STRUCTURE.md` puts the merc gear editor and lookup management in M15, while `PLAN.md`'s M15 title covers only lookup/flag editors, bulk operations, and cross-version compare.
- **Carried-forward limits:** no undo/redo; list/dict/nested fields read-only; Boolean still edited as text `0/1`; column layout not persisted; translation-report messages stay English; no side-by-side or auto-fill; manual GUI pass for M14/M14.5 not performed (automated tests only); `Columns` for non-lookup tables is empty by design.

**Why:** This closes the M6/M10/M13 limitation where `Columns` was empty and validation was inactive, without expanding sparse records or blindly importing stale legacy fields.

**How to apply:** Use `ColumnHints` for present-field refinement; only add `Columns` when declaring absent fields is intentional. Do not add hints for lookup-table `id`/`name` because they would override the deliberate `Raw`/`Integer` Columns types. Main-table lookup combos and named bit labels are still open for M15. See [[ja2-editor-metadata]], [[legacy-reference-findings]], and [[ja2-v4-v5-data-facts]].
