- **M5 overlays:** `OverlayDocument` + `TableFileLoader.LoadOverlayAsync` (loads an overlay without requiring the table's own record element), `OverlayKeyResolver` (scalar/positional/singleton segments), `OverlayMerger` (merged cells with `IsTranslated` and base fallback, nested path form `GEARKIT[1]/mGearKitName`), `OverlayWriter` (writes only into the overlay; a new record is key + the edited field only), `TableEditSession` (routes translatable+language to overlay else base, independent saves), `TranslationAnalyzer` (missing/orphan/duplicate/empty/identical/KeyCountMismatch/UnresolvableKey).
- **Nested overlay edits:** `OverlayRecordKey` carries the primary key plus positional/aggregate nested keys as text; `OverlayWriter` creates missing `GEARKIT`/`ASSIGNMENT`/`COUNTRY` containers on demand. Tables whose records sit in a nested list (`Map.Cities` → `CITYLIST/CITY`) are merged through the XML + resolver, but `TableDocument.Records` is empty for them, so non-translatable field editing for such tables is not wired yet. The loader suppresses the record-element diagnostic when the primary key path is nested.
- **M14 committed (`7075b0f`, 2026-10-24):** per-tab language selector in `TableView` (base + existing overlays + creatable languages); `TableEditorViewModel` reloads the workspace on switch, asks before discarding dirty edits, and persists the choice via `LanguageChanged` → `MainViewModel`/`AppSettings.ActiveLanguageCode`. Untranslated markers: `TableRowViewModel.TranslationState` (only base-valued translatable fields) drives a per-column `DataGridTextColumn.ElementStyle` trigger through `TranslationStateConverter`, with `*` in the header; `DetailFieldViewModel.IsUntranslated` renders a dot. Report: `Workspace.AnalyzeTranslations()` → `TranslationReportWindow` (summary by kind + issues, localized kind labels; analyzer messages stay English). Overlay creation: `OverlayDocument.CreateAsync` writes only the metadata root (UTF-8 no BOM, no base copy) and refuses to overwrite; `IDataSetSession.EnsureOverlayAsync` builds the descriptor and loads/creates the file; translations are then written lazily by `OverlayWriter`. Non-translatable edits in language mode go to the base table with a status warning. `MainViewModel.OpenTableAsync` re-reads the catalog so an overlay created in a tab is seen after close/reopen. Status: 205 tests green (22 Core, 90 Xml, 25 Data, 19 Imaging, 49 App), v4 corpus with real `Russian.Items` overlay and v5 corpus green, build 0 warnings with `-warnaserror`. Limits: no side-by-side compare/auto-fill, new overlay starts empty, list/dict/nested read-only.
