# XML Editor Reloaded — руководство пользователя

**Русский** | [English](USER-GUIDE.md)

Редактор предназначен для просмотра и правки XML-таблиц `TableData` мода **Jagged Alliance 2
1.13**. Он не является установщиком мода и не создаёт новые таблицы «с нуля»: он работает с уже
установленной игрой и её `Data-1.13`.

## 1. Требования и установка

- Windows 10/11 x64.
- Установленная JA2 1.13 с каталогом `Data-1.13\TableData`.
- Для изображений — каталоги `Data-1.13\BigItems`, `Data-1.13\Interface` и
  `Data-1.13\tilesets\0`.
- Для варианта framework-dependent — [.NET 10 Desktop Runtime x64](https://dotnet.microsoft.com/download/dotnet/10.0).
  Self-contained сборке runtime не нужен.

Релиз поставляется в двух вариантах. Распакуйте архив в любую папку и запустите
`XmlEditorReloaded.App.exe`:

| Архив | Что внутри |
|---|---|
| `XmlEditorReloaded-<версия>-win-x64.zip` | Self-contained: .NET runtime уже внутри |
| `XmlEditorReloaded-<версия>-win-x64-framework-dependent.zip` | Только приложение; нужен .NET 10 Desktop Runtime x64 |

Windows может показать SmartScreen, потому что сборка не подписана коммерческим сертификатом.
Проверьте SHA-256 архива по файлу `.sha256`:

```powershell
Get-FileHash .\XmlEditorReloaded-1.1.0-win-x64.zip -Algorithm SHA256
Get-FileHash .\XmlEditorReloaded-1.1.0-win-x64-framework-dependent.zip -Algorithm SHA256
```

### Переносимый режим

`start-portable.cmd` задаёт `XER_APP_DATA=%~dp0data` и запускает редактор. В этом режиме настройки,
layout, `metadata.sqlite` и лог лежат в папке `data` рядом с программой, а не в профиле Windows.

При обычном запуске эти файлы находятся в `%AppData%\XmlEditorReloaded`:

| Файл | Назначение |
|---|---|
| `settings.json` | каталоги данных, тема, язык интерфейса |
| `layouts.json` | ширины и порядок колонок |
| `metadata.sqlite` | метабаза таблиц, связей, lookup и переводов |
| `XmlEditorReloaded.log` | журнал операций и ошибок |

Удаление этих файлов сбрасывает настройки и layout; XML-файлы игры при этом не затрагиваются.

## 2. Первый запуск

1. Нажмите **Обзор** рядом с полем каталога данных.
2. Выберите каталог игры, каталог `Data-1.13` или сразу `Data-1.13\TableData` — редактор сам
   найдёт `TableData`.
3. Слева появятся вкладки **Дерево** и **Список**. Дерево группирует таблицы по папкам, список
   показывает плоский перечень.
4. Дважды щёлкните таблицу, чтобы открыть её во вкладке.

Каталог можно сменить в любой момент. Открытые вкладки сохраняют свой датасет; несколько датасетов
(v4 и v5) можно держать открытыми одновременно.

## 3. Основное окно

- **Дерево/Список** — навигация по таблицам; есть фильтр, «Свернуть всё», «Развернуть всё» и
  «Найти в дереве».
- **Вкладки редакторов** — каждая открытая таблица живёт в своей вкладке. Закрытие вкладки с
  несохранёнными правками требует подтверждения.
- **Grid** — таблица записей. **Детали** справа показывают поля выбранной записи.
- **Панель замечаний** — результаты проверки текущей таблицы.
- **Строка состояния** — путь, число записей, результат операции и ошибки.

Переключение **Grid / XML** находится на вкладке таблицы (Ctrl+E). В режиме XML текст доступен
только для чтения; правка выполняется в Grid.

## 4. Редактирование таблицы

- Выберите ячейку и измените значение. Для lookup-полей предлагается список имён; в поле хранится
  исходный идентификатор.
- **Enter** фиксирует значение, **Esc** отменяет ввод (поведение зависит от типа редактора).
- **Ctrl+Z / Ctrl+Y** — отмена и повтор правок до сохранения.
- **Ctrl+S** — сохранить активную таблицу, **Ctrl+Shift+S** — сохранить все открытые.
- **Insert** — добавить запись, **Ctrl+D** — дублировать, **Delete** — удалить.
- Фильтры: **Ctrl+Shift+A** добавить условие, **Ctrl+Shift+X** очистить, **Ctrl+G** перейти к
  значению.
- Массовая правка: выделите несколько строк и нажмите **Массовая правка**. Для lookup-колонок
  можно выбрать имя из списка.
- **Сбросить layout** в настройках возвращает ширины и порядок колонок по умолчанию.

Записи разрежены: отсутствующие элементы не добавляются автоматически. Неизвестные элементы и
атрибуты сохраняются при записи.

## 5. Детали, связи и изображения

- Панель **Детали** показывает поля выбранной записи, включая lookup-имена, флаги и связанные
  таблицы.
- Кнопка перехода по связи открывает целевую таблицу и выбирает запись.
- Для lookup-значений доступны:
  - **Ctrl+L** — изменить ID (свободный бит для маски, следующий ID для последовательности);
  - **Ctrl+U** — «Где используется» с переходом к первой записи;
  - удаление и смена ID используемого значения блокируются.
- **Изображения** открывают просмотр Big/Medium/Small. Можно выбрать тип, листать кадры и видеть
  live-миниатюры в гриде.
- **Item editor** показывает предмет и его подтаблицы; **Merc gear** — пять комплектов снаряжения;
  **Map.Cities** и **Map.FacilityTypes** имеют отдельные вложенные редакторы.

## 6. Переводы и оверлеи

- В v4 базовая локализация русская, в v5 — английская. Отсутствие `Russian.*` в v5 — норма.
- Оверлей — файл `<Language>.<BaseFile>.xml` в `TableData`. Он содержит ключ и только
  переопределённые поля.
- Выберите язык в редакторе. Правка перевода записывается **только в оверлей**; базовый файл не
  меняется.
- Непереведённое поле показывается из базы с пометкой. Новый оверлей создаётся лениво и только с
  ключом и переводимыми полями.
- **Отчёт по переводам** показывает недостающие, «сиротские» и пустые переводы. Автозаполнения
  нет.
- Для вложенных структур используются отдельные ключи: `uiIndex` для городов, `ubAssignmentType`
  для назначений, номер набора для merc gear.

## 7. Проверка и поиск по датасету

- **Ctrl+Shift+P** — проверить все таблицы. Отчёт показывает ошибки, предупреждения и информацию;
  повреждённый или нечитаемый файл становится ошибкой отчёта, а не срывом проверки.
- Фильтры по важности и тексту, экспорт в Markdown/CSV.
- Двойной щёлчок по замечанию открывает таблицу и выбирает запись.
- **Ctrl+Shift+F** — глобальный поиск по значениям базы и оверлеев. Результат содержит таблицу,
  ключ, путь поля, значение и язык. Переход открывает нужную запись.

Проверка только читает файлы и ничего не исправляет.

## 8. Сравнение v4 и v5

Кнопка **Сравнить** открывает выбор двух каталогов. Сравнение:

- сопоставляет записи по объявленному ключу, а при его отсутствии — по порядку;
- сравнивает значения лексемно (`1.0` и `1` — разные значения);
- сравнивает оверлеи по записанным ячейкам;
- отдельно сравнивает корневые singleton-поля (`COUNTRY`);
- ограничивает объём деталей, но сохраняет точные счётчики;
- экспортирует отчёт в Markdown/CSV.

## 9. Режим XML

- **Ctrl+E** переключает Grid и XML.
- XML — read-only снимок **базовой** таблицы; оверлеи и дочерние таблицы в него не входят.
- **Копировать** копирует текст, **Обновить** перечитывает снимок.
- Поиск принимает ID/ключ записи и выделяет открывающий тег, например `<WEAPON>`.
- В Grid выбор замечания валидации переходит к строке записи. Для замечания дочерней таблицы
  item-workspace редактор сообщит, что таблицу нужно открыть отдельно.
- Текст в XML-режиме не редактируется.

## 10. Горячие клавиши

| Клавиши | Действие |
|---|---|
| Ctrl+O | открыть таблицу |
| Ctrl+S | сохранить активную таблицу |
| Ctrl+Shift+S | сохранить все |
| Ctrl+Z / Ctrl+Y | отменить / повторить |
| Ctrl+F | поиск по таблице |
| Ctrl+Shift+T | найти выбранную запись в дереве |
| Ctrl+E | Grid / XML |
| Ctrl+Shift+P | проверка датасета |
| Ctrl+Shift+F | поиск по датасету |
| Ctrl+, | настройки |
| Ctrl+W | закрыть вкладку |
| F5 | перечитать таблицу |
| F8 | проверить текущую таблицу |
| F1 | контекстная справка по активной таблице и полю |
| Insert | добавить запись |
| Ctrl+D | дублировать запись |
| Delete | удалить запись |
| Ctrl+L | изменить ID lookup-значения |
| Ctrl+U | где используется lookup-значение |
| Ctrl+Shift+A | добавить фильтр |
| Ctrl+Shift+X | очистить фильтры |
| Ctrl+G | перейти к значению фильтра |
| Ctrl+N | новый предмет (item workspace) |

`F1` и **«Справка → Контекстная справка»** открывают справку по полям активной таблицы и
текущей ячейки. Окно ищет по всей справке и переходит по связанным документам; кнопка
**«Открыть таблицу»** открывает связанную таблицу в главном окне. **«Справка → Глоссарий»**
и **«Справка → Индекс»** открывают список терминов и сгенерированный индекс таблиц.
**«Справка → О программе»** остаётся в меню без горячей клавиши.

## 11. Целостность и восстановление

- Перед первым сохранением сделайте резервную копию `TableData`: автоматического backup XML нет.
- Сохранение атомарное; файл перезаписывается только при наличии реальных изменений.
- Внешние изменения файла проверяются по длине и времени модификации. При конфликте редактор
  предложит перечитать файл или явно перезаписать его.
- Повреждённый XML показывается диагностикой; такой файл не сохраняется и не перезаписывается.
- Ошибки сохранения и preflight пишутся в `XmlEditorReloaded.log`.
- Если приложение не может писать в `%AppData%`, запустите `start-portable.cmd` или задайте
  `XER_APP_DATA` на каталог с правом записи.
- `References/` и оригинальные `TableData` не изменяются без явного сохранения. Для экспериментов
  используйте копию датасета.

## 12. Известные ограничения

- XML-снимок показывает только базовую таблицу и не является редактором текста.
- Автоматического backup и three-way merge нет.
- Некоторые таблицы без seed-метаданных показываются через document-driven fallback; новые поля
  сохраняются, даже если у них ещё нет описания.
- Интерфейс и справка локализованы на русский и английский; язык переключается в настройках
  и применяется после перезапуска. Содержание справки следует языку интерфейса.

## Сообщить о проблеме

Используйте [GitHub Issues](https://github.com/shogun-kub/XML-Editor-Reloaded/issues). Укажите
версию приложения, версию Windows, версию датасета (v4 или v5), затронутую таблицу, точные шаги,
ожидаемое и фактическое поведение и соответствующую часть `XmlEditorReloaded.log`. Не прикладывайте
оригинальные файлы `TableData`; при необходимости добавьте только минимальный обезличенный
XML-фрагмент.
