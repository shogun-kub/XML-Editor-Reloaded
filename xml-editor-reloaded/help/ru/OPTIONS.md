# Игровые опции, меняющие смысл полей

Некоторые поля TableData читаются только тогда, когда включена необязательная игровая
система. На этой странице перечислены такие переключатели и указаны поля, на которые они
влияют. Авторитетными остаются файл игровых опций и код времени выполнения; документы
таблиц описывают влияние на поле.

## Chance to Hit: NCTH and OCTH

В игре две модели прицеливания:

- **OCTH** — старая модель шанса попадания, исходный расчёт JA2.
- **NCTH** — новая модель шанса попадания, выбираемая опцией `NCTH` в файле игровых опций.
  `NCTH = TRUE` включает её; `FALSE` оставляет OCTH. В многопользовательской игре NCTH
  принудительно отключена, поэтому поля, относящиеся только к NCTH, там не читаются.

Поля `Items`, относящиеся только к NCTH:

- `ScopeMagFactor`
- `ProjectionFactor`
- `RecoilModifierX`
- `RecoilModifierY`
- `PercentRecoilModifier`
- `PercentAccuracyModifier`
- три группы стоек `STAND_MODIFIERS`, `CROUCH_MODIFIERS` и `PRONE_MODIFIERS`

У таблицы оружия есть собственные поля NCTH (точность, отдача и данные прицеливания); они
будут описаны в будущем документе `Weapons`. Не применяйте поле, относящееся только к NCTH,
к балансу OCTH, не проверив состояние опции.

## Инвентарь: OIV и NIV

В игре две модели инвентаря:

- **OIV** — старый инвентарь, исходная модель слотов/карманов JA2.
- **NIV** — новый инвентарь, модель разгрузки/карманов 1.13.


Модель инвентаря выбирается при старте новой кампании; выбор сохраняется в сохранении.
Поставляемый набор данных 1.13 — это NIV, но OIV по-прежнему поддерживается.
`OLD_INVENTORY_ITEM_NUMBER` (по умолчанию `99`) — маркер размера предмета для предметов,
которые не появляются в NIV; это вспомогательное средство совместимости, а не замена таблицы
предметов.

Затронутые поля в `Items`:

- `ubPerPocket` — вместимость кармана в OIV. В OIV задаёт число одинаковых предметов в
  кармане; NIV выводит вместимость из таблиц `Pockets`/`LoadBearingEquipment` и `ItemSize`.
  Поле **не является строго только для OIV**: код описания предмета в NIV всё ещё читает его
  для свойства «small», потому что `FitsInSmallPocket` возвращает true для любого предмета в
  NIV. Запись поля в `Items.md` помечена как `inferred` для части, зависящей от опции.
- `NewInv` — помечает предмет как доступный только в NIV; OIV его не показывает.
- `ItemSize` — класс размера предмета. Он входит в определение предмета в обеих моделях, но
  проверки карманов различаются. В NIV предмет с `ItemSize == OLD_INVENTORY_ITEM_NUMBER`
  (по умолчанию `99`) считается доступным только в OIV и недоступен.

Прочие подробности OIV/NIV находятся в документах `Pockets`, `PocketPopups` и
`LoadBearingEquipment` (B3).

## Прочие поля, зависящие от опций

| Опция | Поле | Эффект |
|---|---|---|
| Режим Sci-Fi | `Items.SciFi` | Помечает предмет как часть набора предметов Sci-Fi. |
| Tons of Guns | `Items.BigGunList` | Включает предмет в расширенный список оружия. |
| Система болезней | `Items.DiseaseSystemExclusive` | Помечает предмет, относящийся к системе болезней. |

Это флаги предметов, а не глобальные переключатели, хранящиеся в таблице; опция решает,
доступен ли помеченный предмет или активен ли он.

## Что не является глобальной опцией

`AttachmentSystem`, `AttachmentClass`, `nasAttachmentClass` и `nasLayoutClass` — данные
системы навески для отдельного предмета. Они выбирают поведение OAS/NAS для одного предмета;
это не глобальные игровые опции. Различие OAS/NAS описано вместе с полями навески.

## Источники

- Определения игровых опций для `NCTH`, `OLD_INVENTORY_ITEM_NUMBER` и переключателей функций.
- Данные таблицы предметов и группировка опций в устаревшем редакторе предметов.
- Таблицы инвентаря и навески, которые получают значения.

Переключатель инвентаря и поведение `ubPerPocket`/`ItemSize` проверены по поставляемому
исходному коду C++. Ссылки на файлы и строки кода здесь не используются; устойчивые
ориентиры — имена опций и эффекты полей.
