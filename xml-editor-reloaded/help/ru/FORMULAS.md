# Связанные формулы

На этой странице собраны многоступенчатые расчёты, которым не место в описании одного поля.
Она написана для моддеров и для будущей контекстной справки; авторитетным источником
остаётся код на C++. Все вычисления ниже — целочисленные, если значение не помечено как
`FLOAT`.

## Как читать формулы

- `trunc` означает целочисленное деление в C++; дробная часть отбрасывается на этом шаге.
- `max(1, divisor)` означает, что код защищается от нулевого делителя. В данных XML следует
  использовать ненулевые делители, но формула записана так, как её выполняет код.
- `roll(n)` возвращает целое число от `0` до `n-1`; эта же схема используется во всех
  формулах ниже.
- Формулы описывают путь кода по умолчанию. Опции, уровни сложности, черты и тип цели могут
  добавлять ветвления; эти ветвления названы там, где они важны.
- Порядок операций важен. Одни и те же числа, применённые в другом порядке, могут дать
  другой целочисленный результат.

## Armour protection

Игра обрабатывает попадание по каждому предмету брони отдельно, а затем вычитает суммарную
защиту из урона пули. Расчёт состоит из двух проходов: один — по каждому предмету брони,
другой — объединяет слоты брони.

### Входные данные для одного предмета брони

| Обозначение | Значение | Источник |
|---|---|---|
| `P0` | исходная защита | `Armours.ubProtection` |
| `C` | покрытие, проценты | `Armours.ubCoverage` |
| `S` | текущее состояние, 0..100 | свойство предмета `objectStatus` |
| `D` | износ за попадание, проценты | `Armours.ubDegradePercent` |
| `I` | входящий урон | урон пули после коэффициента живучести боеприпаса и шага случайности/точности |
| `K` | класс брони | `Armours.ubArmourClass` |

### Покрытие и состояние

Проход по броне сначала проверяет, покрывает ли броня попадание вообще:

```
r1 = roll(100) + 1
if r1 > C:
    if K == VEST and not AmmoTypes[type].ignoreArmour:
        return I / 2
    return 0
```

Таким образом, `C = 100` покрывает всегда. Жилет всё равно вдвое уменьшает урон при промахе
по покрытию, если боеприпас не игнорирует броню; другие классы при промахе дают нулевую
защиту.

Если броня задета, код проверяет слабое место, используя текущее состояние:

```
r2 = roll(100) + 1
if r2 > S:
    P0 = P0 - (r2 - S)
    if P0 < 0:
        if K == PLATE: plateHit = true
        return 0
```

Поэтому повреждённый предмет теряет защиту двумя путями: его состояние снижает порог слабого
места, а неудачный бросок напрямую уменьшает `P0`.

`plateHit` начинается с `false` и устанавливается, когда задета пластина или когда защита
пластины не сработала. Он принудительно задаёт `C = 100` для следующей проверки пластины,
поэтому пластина, уже находящаяся на пути попадания, не бросает покрытие повторно.

### Поправка на боеприпас и применяемая защита

```
P = trunc(P0 * AmmoTypes[type].armourImpactReductionMultiplier
                / max(1, AmmoTypes[type].armourImpactReductionDivisor))
```

Коэффициенты берутся из `AmmoTypes`; два поля-делителя — целые числа, а не проценты.
Результат `P` — защита, которую броня фактически даёт после модификатора пробития
боеприпаса.

Затем код выбирает величину, используемую для износа:

```
if P > I:
    A = I
else:
    A = P0
```

Когда пуля остановлена (`P > I`), применяется только урон. Когда пуля не остановлена, код
использует для расчёта износа исходную защиту `P0`, а не скорректированную боеприпасом `P`.

### Износ и особые боеприпасы

```
if AmmoTypes[type].acidic:
    S = S - 3 * A * D / 100
    P = P / 2
else if AmmoTypes[type].ignoreArmour and (K == VEST or K == LEGGINGS):
    P = 0

S = S - A * D / 100
if K == PLATE: plateHit = true
return P
```

Кислотный боеприпас даёт вчетверо больший износ (дополнительные `3x`) и вдвое уменьшает
защиту после шага износа. `ignoreArmour` обнуляет защиту жилета и леггинсов после расчёта
износа, поэтому броня всё равно теряет состояние, даже когда не останавливает попадание.

### Какая броня проверяется

Проход по суммарной броне выбирает слот по месту попадания:

| Место попадания | Слот |
|---|---|
| голова | шлем |
| ноги | леггинсы |
| корпус / по умолчанию | жилет |
| железа | нет; возвращается 0 |

При попадании в корпус он также может использовать броню, прикреплённую к жилету (например,
плитоноску). Код берёт первое вложение `IC_ARMOUR` с состоянием выше нуля, добавляет его
защиту (умноженную на 3 для бронежилета, когда учитываются осколки), а затем проверяет
основную броню и её первое броневое вложение, если урон всё ещё больше накопленной защиты.
Сама основная броня добавляется последней. Поэтому жилет вместе с пластиной может остановить
больше, чем любой из предметов по отдельности.

Итоговый результат для попадания:

```
totalProtection = totalArmourPass(...)
impactAfterArmour = impactBeforeArmour - totalProtection
```

Затем применяется правило минимального урона из раздела
[Урон от боеприпасов и оружия](#ammo-and-weapon-damage-dealt). Пластина также может
сломаться, когда её состояние опускается ниже порога пригодности.

### Связанные данные

- [Armours](tables/Items/Armours.md) — защита, покрытие, износ и класс.
- `AmmoTypes` — множители пробития брони и урона.
- Расчёт находится в игровом коде брони/защиты; ссылки на файлы и строки исходников в этой

## Ammo and weapon damage dealt

Это конвейер, а не одна замкнутая формула. Выход каждого этапа служит входом следующего;
приведённые ниже названия описывают этапы.

### 1. Базовый урон оружия

Для огнестрельного оружия шаг базового урона начинается с `ubImpact` оружия и применяет
модификатор урона по типу оружия, бонус урона предмета и глобальный модификатор урона оружия:

```
B0 = Weapon[item].ubImpact
B1 = trunc(B0 * fDamageModifierGun[Weapon[item].ubWeaponType])
B2 = B1 + itemDamageBonus
B  = min(255, globalGunAdjustment(B2))
```

`ubImpact` — поле `Weapons.ubImpact`; `fDamageModifierGun` — множитель из настроек предмета по
типу оружия. Точный состав бонуса урона предмета зависит от вложений и черт; он добавляется
до глобальной поправки урона оружия, а не после.

### 2. Несколько снарядов

Если боеприпас выпускает больше одного снаряда, базовый урон делится между ними до попадания:

```
if AmmoTypes[type].numberOfBullets > 1:
    B = trunc(B * AmmoTypes[type].multipleBulletDamageMultiplier
                / max(1, AmmoTypes[type].multipleBulletDamageDivisor))
```

### 3. Коэффициент боеприпаса и цели

```
F = AmmoTypes[type].dDamageModifierLife
if target is zombie:
    F = F * dDamageModifierZombie
else if target is vehicle or robot:
    if jeep / robot: F = F * dDamageModifierArmouredVehicle
    else if tank:    F = F * dDamageModifierTank
    else:            F = F * dDamageModifierCivilianVehicle
if target is a robot with a chassis damage-reduction modifier in (0, 1):
    F = F * fRobotDamageReductionModifier
```

Ветвление для корпуса робота также изнашивает бронеплиту корпуса на
`max(1, originalImpact / 12)` до применения коэффициента урона.

### 4. Случайная удача и бонус за точность

```
I0 = trunc(B * F)
fluke = roll(51) - 25          // -25 .. +25
bonus = hitMargin / 2                  // up to +50
I1 = I0 * (100 + fluke + bonus) / 100
if I1 < 1: I1 = 1
```

Запас попадания передаётся пулей; это не итоговый шанс попадания. Случайная удача отражает
попадания по органам, удачно подвернувшуюся зажигалку и подобные случайные события.

### 5. Фугасные боеприпасы

```
if AmmoTypes[type].highExplosive:
    I1 = trunc(I1 * beforeArmourDamageMultiplier
                  / max(1, beforeArmourDamageDivisor))
    if target is tank: I1 = I1 / 2
```

### 6. Вычитание брони

```
armour = totalArmourPass(target, hitLocation, I1, ammoType, fragments)
I2 = I1 - armour
```

Если попадание — особое «ослепление плевком», шаг брони пропускается и `I2 = I1`.

### 7. Минимальный урон

```
if AmmoTypes[type].zeroMinimumDamage:
    I2 = max(0, I2)
else:
    I2 = max(I2, (I1 + 5) / 10)
    if numberOfBullets > 1 and pelletsHitBy > 0:
        I2 = I2 + (pelletsHitBy - 1) / 2
```

Нижняя граница по умолчанию — 10 % урона до брони, округлённые вверх целочисленным делением.
Боеприпас с `zeroMinimumDamage` может нанести нулевой урон, но всё равно проходит через
последующие этапы.

### 8. Коэффициент боеприпаса после брони

```
I3 = trunc(I2 * afterArmourDamageMultiplier
              / max(1, afterArmourDamageDivisor))
```

### 9. Бонусы черт

Новая система черт может добавлять урон после коэффициента боеприпаса:

- метательные ножи с чертой «метание»: процент от `I3`, зависящий от значения черты и времени
  прицеливания;
- черта снайпера: процент от `I3` за каждый шаг прицеливания сверх настроенного порога.

Эти бонусы прибавляются к `I3`, а не умножают базовый урон оружия.

### 10. Сопротивление урону

```
I4 = max(0 or 1, trunc(I3 * (100 - target.damageResistance) / 100))
```

Нижняя граница — `0` для боеприпасов с `zeroMinimumDamage` и `1` в остальных случаях.
Сопротивление урону цели объединяет сопротивления брони/робота/существа цели и текущее
состояние сложности/опций; это не только значение брони из `Armours`.

### 11. Место попадания и критические удары

Поправка по месту попадания выполняется после сопротивления. Она может добавлять критический
урон при попаданиях в голову, корпус и ноги и формирует отдельное значение критического
удара, которое использует код ран/потери характеристик. Эффекты наркотиков, криозаморозка,
сбивание с ног и другие особые эффекты выполняются после этого базового конвейера.

### Связанные данные

- [Armours](tables/Items/Armours.md) — броня, уменьшающая результат.
- [Magazines](tables/Items/Magazines.md) — предмет-боеприпас, который задаёт тип боеприпаса.
- `AmmoTypes` — урон, пробитие, число снарядов и флаги особых боеприпасов.
- `Weapons` — базовый урон и модификатор по типу оружия.
- Расчёт находится в игровом конвейере урона; ссылки на файлы и строки исходников в этой
  справке не приводятся.

## Карта формул

| Формула | Используемые данные |
|---|---|
| Защита брони | `Armours`, `AmmoTypes` |
| Суммарная броня | `Armours`, `Items` |
| Базовый урон оружия | `Weapons`, `Items` |
| Урон пули | `AmmoTypes`, `Weapons`, `Armours` |

## Открытые вопросы

- Формулы выше описывают обычный путь огнестрельного оружия. Ближний бой, взрывы, строения и
  ветвления для техники — отдельные и здесь не документированы.
- Бонус урона предмета и глобальная поправка урона оружия — это этапы; они не разложены на
  прибавки от каждого вложения и каждой черты. Эти прибавки относятся к `Items` и `Weapons`,
  когда те таблицы будут описаны.
- Сопротивление урону цели — агрегат; оно будет описано вместе с таблицами профилей солдат и
  брони, если пользователь об этом попросит.
