## [1.1.0] — 2026-11-12

Контекстная справка по полям `TableData` и полная русская версия справки.

### Добавлено

- Встроенная справка по 239 таблицам и 2985 путям полей: 94 документа с описаниями,
  значениями, диапазонами, источниками и ссылками на связанные таблицы.
- Немодальное окно справки, `F1`, кнопка «?» в панели деталей и тултипы заголовков колонок.
- Поиск по таблицам, полям и описаниям, переход по связанным таблицам и открытие таблицы
  из справки в основном окне.
- Страницы «Глоссарий», «Индекс», «Покрытие», «Формулы», «Источники», «Параметры игры»,
  «Локализация» и «Тексты писем».
- Полная русская справка в `help/ru` с теми же путями, якорями и полями; выбор
  `help.json`/`help.ru.json` по языку интерфейса и английский fallback.
- `help-check -Lang ru` для структурного паритета, статус перевода и русские
  сгенерированные индекс/покрытие.

### Изменено

- Строка `Launchables` в русском интерфейсе приведена к глоссарию: «Боеприпасы».
- USER-GUIDE уточняет, что язык справки следует языку интерфейса после перезапуска.

### Проверка

- 745 unit-тестов в пяти xUnit-проектах.
- `help-check -Release` и `help-check -Lang ru -Release`: 94/94 документа, 239/239 таблиц,
  2985/2985 путей.
- `help.json` и `help.ru.json --check` — без расхождений.
- UI-smoke опубликованной сборки: S81 (About показывает `1.1.0`) и S105 — PASS.
- UI-smoke S105 (v4, ru): русский тултип, F1, поиск, ссылка, открытие таблицы, глоссарий,
  индекс и закрытие.

## [1.0.0] — 2026-11-05

Первый публичный portable-релиз редактора.

### Добавлено

- Self-contained сборка `win-x64`: .NET runtime внутри архива, установка не требуется.
- Framework-dependent сборка `win-x64`: меньше по размеру, требует .NET 10 Desktop Runtime x64.
- Оба архива содержат одинаковые README/USER-GUIDE/CHANGELOG/LICENSE, launcher и отдельный SHA-256.
- Portable-архив с README, руководством пользователя, changelog, лицензией и third-party notices.
- `start-portable.cmd` для хранения настроек, layout, метабазы и лога рядом с программой.
- SHA-256 checksum для каждого архива.
- Иконка приложения и версия `1.0.0` в метаданных сборки и окне «О программе».
- CI-гейты сборки и тестов, release-workflow по тегу `v*`.

### Возможности редактора

- Просмотр и редактирование таблиц `TableData` v4 и v5 в schema-driven grid.
- Дерево и список таблиц, поиск, вкладки, несколько датасетов одновременно.
- Item master-detail, merc gear, shopkeeper, вспомогательные и вложенные редакторы
  (`Map.Cities`, `Map.FacilityTypes`).
- Lossless round-trip, сохранение только изменённых файлов, undo/redo, массовые правки и фильтры.
- Локализационные оверлеи: перевод пишется только в оверлей, база не меняется.
- Lookup- и flag-редакторы, распределение свободных ID, «Где используется» с защитой значений.
- Сравнение v4↔v5 по структуре и значениям, копирование строк с remap.
- Проверка всего датасета одним отчётом и глобальный поиск по таблицам и оверлеям.
- Просмотр STI-изображений Big/Medium/Small с выбором кадра.
- Глобальный Grid/XML: read-only снимок базовой таблицы, поиск по ID/ключу и переход из замечания
  валидации к записи.
- Тёмная, светлая и системная темы; русский и английский интерфейс.

### Проверка

- `dotnet build -warnaserror`: 0 ошибок, 0 предупреждений.
- 726 unit-тестов в пяти xUnit-проектах.
- Полный UI-smoke: 99/99 (98 автоматических сценариев + S50), 0 ошибок.
- Ручной v5-gate: S04/S22/S53 — PASS, S74 — N/A (отдельной сетки нет), ветка ошибки сохранения
  S13 — PASS; baseline `TableData` unchanged.
- Self-contained и framework-dependent publish, содержимое обоих ZIP и checksum проверены
  release-скриптом.
- Корпусные прогоны v4/v5 — 726/726, compare — 1/1, copy — 1/1, perf — 9/9 на каждом корпусе;
  они требуют локальных копий `References/` и не входят в обычный CI.

### Известные ограничения

- Автоматического backup XML и three-way merge нет.
- XML-режим только читает базовую таблицу; оверлеи и дочерние таблицы в снимок не входят.
- Сборка не подписана коммерческим сертификатом; Windows SmartScreen может показать предупреждение.
