## [1.0.0] — 2026-11-05

Первый публичный portable-релиз редактора.

### Добавлено

- Self-contained сборка `win-x64`: .NET runtime внутри архива, установка не требуется.
- Portable-архив с README, руководством пользователя, changelog, лицензией и third-party notices.
- `start-portable.cmd` для хранения настроек, layout, метабазы и лога рядом с программой.
- SHA-256 checksum для каждого архива.
- Иконка приложения и версия `1.0.0` в метаданных сборки и окне «О программе».
- CI-гейты сборки и тестов, release-workflow по тегу `v*`.

### Возможности редактора

- Просмотр и редактирование таблиц `TableData` v4 и v5 в schema-driven grid.
- Дерево и список таблиц, поиск, вкладки, несколько датасетов одновременно.
- Item master-detail, merc gear, shopkeeper, вспомогательные и вложенные редакторы
  (`Map.Cities`, `Map.FacilityTypes`).
- Lossless round-trip, сохранение только изменённых файлов, undo/redo, массовые правки и фильтры.
- Локализационные оверлеи: перевод пишется только в оверлей, база не меняется.
- Lookup- и flag-редакторы, распределение свободных ID, «Где используется» с защитой значений.
- Сравнение v4↔v5 по структуре и значениям, копирование строк с remap.
- Проверка всего датасета одним отчётом и глобальный поиск по таблицам и оверлеям.
- Просмотр STI-изображений Big/Medium/Small с выбором кадра.
- Глобальный Grid/XML: read-only снимок базовой таблицы, поиск по ID/ключу и переход из замечания
  валидации к записи.
- Тёмная, светлая и системная темы; русский и английский интерфейс.

### Проверка

- `dotnet build -warnaserror`: 0 ошибок, 0 предупреждений.
- 726 unit-тестов в пяти xUnit-проектах.
- Полный UI-smoke: 99/99 (98 автоматических сценариев + S50), 0 ошибок.
- Self-contained publish и содержимое portable ZIP проверены release-скриптом.
- Корпусные, сравнительные, copy- и perf-гейты выполнялись на предыдущих этапах; они требуют
  локальных копий `References/` и не входят в обычный CI.

### Известные ограничения

- Автоматического backup XML и three-way merge нет.
- XML-режим только читает базовую таблицу; оверлеи и дочерние таблицы в снимок не входят.
- Ручная перепроверка S04/S22/S53/S74 на v5 и ветка ошибки сохранения S13 остаются отдельными
  проверками.
- Сборка не подписана коммерческим сертификатом; Windows SmartScreen может показать предупреждение.
